# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.0.1   | ✅ Yes     |

**Note:** We strongly encourage users to run supported versions to ensure they receive timely security patches and updates. Unsupported versions may contain unpatched vulnerabilities.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly to help protect all users.

**How to report:**

* **Email:** [ infosliitmcc@gmail.com](mailto:infosliitmcc@gmail.com)
* **Include:**

  * Description of the vulnerability
  * Steps to reproduce
  * Affected versions
  * Potential impact

**What to expect:**

1. Acknowledge your report within 48 hours.
2. Investigate and assess the severity.
3. Provide updates on the fix timeline if applicable.
4. Confirm resolution once patched.
5. If the report is invalid or not applicable, we will explain why.

**Responsible Disclosure Guidelines:**

* Do not publicly disclose the vulnerability before a fix is released.
* Avoid sharing exploits or proof-of-concepts publicly.
* Cooperating with responsible disclosure helps keep all users safe.
